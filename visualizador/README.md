# Visualizador dos resultados

Acesso direto: https://ricardosqzz.github.io/dissertacao-congonhas/visualizador/ . A seleção pela rosa do vento altera a figura e preserva o recorte analítico documentado. O visualizador também funciona sem conexão quando baixado pelos artefatos de Actions.

As 195 prévias são extraídas dos volumes em partes/ durante a preparação do site. Nenhum arquivo POST, EMI ou base individual de saúde é publicado.
