# Dados consolidados

São derivados mínimos para reproduzir a classificação atual. As geometrias usam SIRGAS 2000 / UTM 23S, EPSG:31983, declarado nos GeoJSON. Não são arquivos RFC7946 destinados a mapas web em longitude/latitude; mantenha o CRS nas operações métricas. Bases brutas e os arquivos horários completos permanecem nas fontes locais documentadas.
